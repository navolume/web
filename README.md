# Navolume Web

Marketing site for [Navolume](https://navolume.com): the home for everything creators sell digitally.

## Local preview

```bash
python3 -m http.server 8080
```

The project is a static site and can be deployed directly on Cloudflare Pages.

## Before sharing broadly

The early-access links target `hello@navolume.com`. Configure Cloudflare Email Routing or an email provider so that address reaches the founder inbox.
